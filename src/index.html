段首空格与空白行

            

              
1. HTML 段首空两格
&emsp;&emsp;
可直接选中复制；预览时会变成两个较宽的空格。

              
2. 中文全角空格
［　　］
方括号中是两个真正的全角空格，不依赖 HTML 实体。

              
3. 只换下一行
<br>
需要强制换到下一行时使用。

              
4. 空出一整行
<br><br>
需要明显留白时使用；连续按很多次 Enter 不会越空越宽。

            

            
这些是 Markdown 中常用的内嵌 HTML；其他平台是否支持，取决于该平台的渲染规则。
